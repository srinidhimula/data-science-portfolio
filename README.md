# Data Science Portfolio

Repository containing portfolio of data science projects (academic, business datasets) completed by me for academia, self learning and hobby purposes.
Presented in the form of Python scripts and Jupyter Notebooks.

**Contents**

- **Workflow Automation, Data Analysis, and Visualization**

	- **Piezoelectric Materials Screening:** In this project, I developed workflows to automate different steps of data preprocessing for simualtions, and post-processing of output files. Using exploratory data analysis and visualizations, identified correlations in data and identified top 10 high performing materials.

		*Tools: Numpy, Pandas, Seaborn, Matplotlib*
